# Archive scope

This private archive contains personal reproduction notes, source-level modifications, and the checked reproduction assets for a video-to-Unitree-G1 motion tracking workflow.

Included: scripts, configuration changes, tests, Markdown technical documentation, the documented GVHMR SMPL CSV inputs, generated G1 NPZ outputs, deployment sources, the deployment ONNX/NPZ inputs, playback helpers, and the accompanying video CSV.

Excluded: unrelated installers and archives, credentials, and network-specific configuration.

Exception: the original, curated demonstration MP4 files under `g1-motion-pipeline/assets/demo/` are included solely as public portfolio evidence. They contain no credentials, model weights, company data, or robot-control commands.

Upstream projects are retained by reference; this archive contains selected local changes plus the documented, self-contained reproduction inputs and outputs.
