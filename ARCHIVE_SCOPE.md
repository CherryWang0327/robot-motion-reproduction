# Archive scope

This private archive contains personal reproduction notes and source-level modifications for a video-to-Unitree-G1 motion tracking workflow.

Included: scripts, configuration changes, tests, and Markdown technical documentation.

Excluded: model weights, datasets, raw motion assets, deployment packages, runtime results, logs, archives, credentials, and network-specific configuration.

Exception: the original, curated demonstration MP4 files under `g1-motion-pipeline/assets/demo/` are included solely as public portfolio evidence. They contain no credentials, model weights, company data, or robot-control commands.

Upstream projects are retained by reference; this archive contains only selected local changes.
